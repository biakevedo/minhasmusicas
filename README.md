Projeto de Biblioteca de Áudio, desenvolvido em Java com foco em orientação a objetos. Possui um pacote de modelos que inclui as classes Audio, MinhasPreferidas, Musica e Podcast. O sistema utiliza herança (extends), encapsulamento com getters e setters, além de polimorfismo para permitir o tratamento genérico de diferentes tipos de mídia. O projeto demonstra boas práticas de organização em pacotes e reutilização de código.
